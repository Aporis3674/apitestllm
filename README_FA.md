## 🌟 قابلیت‌های کلیدی

- 🌈 **بنر متنی ASCII با گرادیانت رنگی RGB**: نمایش تایپوگرافی سه‌بعدی رنگی RGB در هنگام شروع برنامه.
- 🎛 **دکمه‌ها و منوی مینیمال با تم خاکستری**: طراحی مدرن و چشم‌نواز با قابلیت انتخاب سریع از طریق کیبورد.
- ⚡ **پیش‌نمایش انیمیشنی دستورات اسلش (`/`)**:
  - به محض تایپ کاراکتر `/`، یک باکس خاکستری شیک از دستورات موجود درست زیر خط ورودی ظاهر می‌شود.
  - با فشردن کلید Backspace و پاک شدن `/`، باکس به طور خودکار غیب می‌شود.
  - امکان فیلتر زنده و حرکت بین دستورات با کلیدهای جهت‌نما (Arrow Keys) یا کلید Tab.
- 🚀 **دستورات مستقیم و فوری (`/quick` و `/test`)**:
  - `/quick` (یا `/scan`): بررسی می‌کند که آیا می‌خواهید از پروفایل‌های ذخیره‌شده استفاده کنید یا اندپوینت جدید؛ سپس فوراً تمام مدل‌ها را Fetch کرده و تست سلامت موازی می‌گیرد.
  - `/test` (یا `/eval`): امکان انتخاب از پروفایل‌ها یا ورود اندپوینت جدید، انتخاب مدل با کلیدهای جهت‌نما و اجرای بنچمارک زنده برای محاسبه‌ی TTFT و سرعت توکن بر ثانیه.
- 🎯 **انتخاب مدل با کلیدهای جهت‌نما (Arrow-Key Model Picker)**:
  - دریافت خودکار کاتالوگ مدل‌ها از سرور.
  - امکان بالا و پایین رفتن بین مدل‌ها با کلیدهای جهت‌نما **[↑ / ↓]** و انتخاب با کلید **[Enter]**.
  - فیلتر و جستجوی آنی با تایپ هر کلمه‌ای در هر لحظه.
- 🔎 **صفحه اختصاصی وضعیت و سلامت مدل‌ها (Model Discovery Board)**:
  - کاوش تمامی مدل‌های موجود و اجرای تست سلامت موازی با نمایش نوار پیشرفت (Progress Bar).
  - نشانگرهای وضعیت واضح: `[● OK]` (سبز) و `[✖ FAILED]` (قرمز).
  - نمایش دقیق علت خطاها (خطاهای HTTP 401 ،404 ،429 ،502، خطای قطعی اتصال Connection Refused یا Timeout).
- 📊 **محاسبه و بنچمارک دقیق تله‌متری و سرعت مدل**:
  - **TTFT (Time To First Token)**: زمان دریافت اولین توکن بر حسب میلی‌ثانیه (`ms`).
  - **سرعت تولید توکن (TPS)**: تعداد توکن تولید شده در هر ثانیه (`tokens/sec`).
  - **زمان کل پاسخ‌دهی (Latency)** بر حسب میلی‌ثانیه (`ms`).
  - **نمایش استریم زنده پاسخ مدل** و پشتیبانی از توکن‌های Reasoning و تفکر مدل.
- 💾 **مدیریت ماندگار پروفایل‌ها**: ذخیره‌سازی امن اندپوینت‌ها، کلیدها و مدل‌های پیش‌فرض در فایل `~/.api_test_cli/config.json`.

## 🚀 نصب و اجرا

### ۱. پیش‌نیازها
- پایتون نسخه 3.9 به بالا
- نصب پیش‌نیازها با دستور:

```bash
pip install rich httpx
```

### ۲. اجرا
```bash
python api_test.py
```
*در ویندوز می‌توانید مستقیماً فایل `run.bat` را اجرا کنید.*

## 🧭 جدول دستورات اسلش (Slash Commands)

| دستور | میانبر | توضیحات |
|---|---|---|
| `/quick` | `/scan`, `/fetch` | **اسکن سریع**: انتخاب پروفایل یا ورود اندپوینت جدید و بررسی سلامت تمام مدل‌ها |
| `/test` | `/eval`, `/qbench` | **بنچمارک سریع**: انتخاب پروفایل یا اندپوینت، انتخاب مدل و تست لایو TTFT و سرعت |
| `/start` | `1` | شروع کار با پروفایل فعال فعلی |
| `/models` | `m` | نمایش لیست مدل‌ها و جدول وضعیت سلامت برای پروفایل فعال |
| `/bench` | `b` | اجرای بنچمارک سرعت و TTFT برای مدل انتخابی در پروفایل فعال |
| `/stream` | `s` | تست تعاملی چت و نمایش زنده استریم توکن‌ها |
| `/config` | `c` | تغییر یا تنظیم اندپوینت، کلید API و مدل پیش‌فرض |
| `/profiles` | `p` | مدیریت و جابجایی بین پروفایل‌های ذخیره‌شده |
| `/clear` | `cls` | پاک کردن صفحه ترمینال |
| `/back` | `0, ..` | بازگشت به صفحه قبل |
| `/exit` | `2, q` | خروج از برنامه |

## 📁 ساختار فایل‌های پروژه

```
api-test-cli/
├── api_test.py       # اسکریپت اصلی اجرای برنامه
├── cli.py            # حلقه تعاملی REPL و مدیریت منوها و دستورات
├── palette.py        # موتور رندر و انیمیشن پیش‌نمایش دستورات اسلش
├── picker.py         # ماژول انتخاب مدل با کلیدهای جهت‌نما و فیلتر زنده
├── client.py         # موتور ارتباط با API، استریم SSE و تحلیل خطاها
├── ui.py             # کامپوننت‌های بصری Rich، بنر RGB و جداول
├── config.py         # مدیریت ماندگار پروفایل‌ها (~/.api_test_cli/config.json)
├── run.bat           # لانچر تک کلیکی برای ویندوز
├── requirements.txt  # وابستگی‌های پروژه
└── test_suite.py     # تست‌های اعتبارسنجی خودکار
```
